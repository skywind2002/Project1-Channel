## 流程简介

生成原比特流 -> CRC添加校验码 -> 卷积码编码 -> 使用格雷码映射为复数 -> 信道传输 -> 接收信息并通过信道已知信息作修正 -> Viterbi解码 -> 后续处理 -> 结果分析
